# Cart Page Features List

## Navigation & Controls
1. **Back/Close Button** - A button to return to the menu without placing an order
2. **Continue Shopping Button** - Encourage users to keep browsing after viewing cart
3. **Home/Dashboard Button** - In the header for easy navigation to home page

## Cart Management
4. **Remove Item Button** - Quick way to delete items from cart (currently only +/- qty buttons)
5. **Clear Cart Button** - Option to clear entire cart at once with single click
6. **Delete with Confirmation** - Prevent accidental deletions by showing confirmation dialog

## Order Summary
7. **Breakdown Section** - Show detailed cost breakdown including:
   - Subtotal
   - Delivery fee (optional)
   - Estimated tax
   - Final total
8. **Quantity Input Field** - Allow direct typing of quantity, not just +/- buttons
9. **Item Image Thumbnails** - Show small preview images of items in cart for better visual reference

## Checkout Enhancements
10. **Delivery Options** - Radio buttons to select between Delivery/Pickup options
11. **Promo/Discount Code Field** - Input field for coupon codes to apply discounts
12. **Delivery Fee** - Show calculated fee based on delivery address
13. **Estimated Delivery Time** - Display "Estimated delivery in 30-45 minutes"
14. **Payment Method Selection** - Options for Cash/Card/Online payment

## UI/UX Improvements
15. **Collapse/Expand Cart Items** - Accordion-style view for better mobile responsiveness
16. **Recent Addresses** - Dropdown menu of previously used delivery addresses
17. **Save Favorites/Wishlist** - Heart icon to save items for later purchase
18. **Order Progress Indicator** - Show progress after order is placed (Processing, Confirmed, Preparing, etc.)

## Additional Features
19. **Empty State Message** - Clear message when cart is empty with "Continue Shopping" button
20. **Stock/Availability Indicator** - Show if items are available before checkout
21. **Special Instructions Field** - Allow customers to add special requests or dietary notes
22. **Recommended Items Section** - Show "Frequently Bought Together" suggestions
23. **Seasonal Promotions Banner** - Highlight current deals and promotions
24. **Loyalty Points Display** - Show loyalty points earned/balance if loyalty program exists
25. **Order History Quick Access** - Link to view previous orders for reordering
